      About AlgoraeOS

      AlgoraeOS is a biologically informed, attention-aware deep neural network developed by the UNSW Biomedical AI Laboratory in partnership with Algorae Pharmaceuticals. It predicts Bliss, Loewe, HSA and ZIP synergy together, with calibrated uncertainty, and was prospectively validated in vitro. This portal gives access to its predictions.

      Paper

      Multimodal Deep Learning for Calibrated, Dose-Specific Drug Combination Repurposing: A Prospectively Validated AI Framework

      Heydari MJ, Lye B, Mansouri P, Marsland T, Pamulapati K, Vary R, Allen H, Simpson KJ, Lock JG, McKenna J, Vafaee F. Preprint: bioRxiv 10.1101/2025.11.05.686895

      Data availability

      Raw training data: DrugComb portal. Curated and pre-processed data: AlgoraeOS GitHub repository. Validation data: Supplementary Table 11 of the paper.

      Code availability

      The full model implementation is proprietary. Model predictions are available through this portal for single and batch queries.

      About Synergy Metrics

      Bliss Independence

      Expected effect assuming independent drug action

      Loewe Additivity

      Deviation from additivity of the same agent

      HSA (Highest Single Agent)

      Improvement beyond best single agent

      ZIP (Zero Interaction Potency)

      Deviation from zero-interaction potency
